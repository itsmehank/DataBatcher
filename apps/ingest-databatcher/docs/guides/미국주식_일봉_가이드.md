# DataBatcher US Stock 실행 가이드

본 문서는 DataBatcher 프로젝트에서 **미국 주식(NYSE, NASDAQ, ETF)** 데이터를 수집하기 위한 단계별 안내서입니다.

**최종 업데이트**: 2026-02-05

## 프로젝트 개요

DataBatcher US Stock은 미국 주식시장 데이터 수집 및 기술적 지표 계산 시스템입니다.

- **데이터 소스**: FinanceDataReader (FDR)
- **지원 시장**: NYSE, NASDAQ, US ETF
- **핵심 파이프라인**: 데이터 수집(collectors) → 지표 계산(indicators) → DB 저장(savers)

> **참고**: 한국 주식(KRX)과 별도의 테이블을 사용합니다.
> - `us_symbol_master`: 미국 종목 마스터
> - `us_stock_prices`: 미국 주식 가격
> - `us_stock_indicators`: 미국 주식 지표

## 1. 사전 요구사항

- **Python 3.10+** 권장 (3.9 이상 동작 가능)
- **pip** 또는 pipx
- **Docker + Docker Compose** (로컬 MySQL 실행 용도, 권장)
- **MySQL 8.0+** (Docker 사용 또는 별도 설치)
- **FinanceDataReader** 라이브러리 (requirements.txt에 포함)

## 2. 최초 설치 및 실행 (Quick Start)

처음 시작하는 경우, 다음 5단계로 빠르게 시작할 수 있습니다.

**예상 소요 시간**: 5-10분

```bash
# 1. 가상환경 활성화 및 의존성 설치
source .venv/bin/activate  # 또는 .venv\Scripts\activate (Windows)
pip install -r requirements.txt

# 2. Docker MySQL 실행 및 DB 초기화
cd docker && docker compose up -d && cd ..
python apps/ingest-databatcher/scripts/init_db.py

# 3. US 종목 마스터 동기화 (NYSE + NASDAQ + ETF)
python apps/ingest-databatcher/scripts/us_sync_symbol_master.py

# 4. 테스트 데이터 수집 (NASDAQ, symbol 정렬 기준 상위 100개, 최근 1년)
python apps/ingest-databatcher/scripts/us_bulk_update.py \
  --start 2025-01-01 \
  --end 2025-12-31 \
  --market NASDAQ \
  --top 100 \
  --workers 4 \
  --with-indicators

# 5. 일일 업데이트 테스트
python apps/ingest-databatcher/scripts/us_daily_update.py --symbols AAPL MSFT NVDA --with-indicators --force
```

### Step 2: US 종목 마스터 동기화

**목적**: NYSE, NASDAQ, US ETF 상장 종목을 `us_symbol_master` 테이블에 저장

```bash
# 전체 시장 동기화 (기본, yfinance sector 수집 포함)
python apps/ingest-databatcher/scripts/us_sync_symbol_master.py

# yfinance sector 수집 스킵 (빠른 실행, 종목 리스트만 동기화)
python apps/ingest-databatcher/scripts/us_sync_symbol_master.py --skip-yfinance

# yfinance sector 수집 수량 제한 (점진적 수집)
python apps/ingest-databatcher/scripts/us_sync_symbol_master.py --yfinance-limit 500

# 특정 시장만 동기화
python apps/ingest-databatcher/scripts/us_sync_symbol_master.py --market NYSE
python apps/ingest-databatcher/scripts/us_sync_symbol_master.py --market NASDAQ
python apps/ingest-databatcher/scripts/us_sync_symbol_master.py --market ETF
```

**예상 결과**:
- NYSE: ~2,700개 종목
- NASDAQ: ~3,800개 종목
- ETF: ~4,800개 종목
- **총 약 11,000개 종목** (ALL 기준)
- sector/industry 정보가 함께 수집됨 (FDR Industry + yfinance Sector)

**예상 소요 시간**:
- `--skip-yfinance`: 1-2분 (종목 리스트 + FDR Industry만)
- 기본 (yfinance 포함): ~1시간 (STOCK ~6,500개 × 2 req/sec)
- `--yfinance-limit 500`: ~5분 (500개만 yfinance 호출)

> **참고**: yfinance는 증분 처리됩니다. sector가 NULL인 STOCK 종목만 대상이므로,
> 한 번 전체 수집 후에는 신규 상장 종목만 처리하여 시간이 크게 단축됩니다.

**확인 방법**:
```bash
# MySQL CLI로 확인
mysql -h 127.0.0.1 -u YOUR_DB_USER -pYOUR_DB_PASSWORD market -e "
  SELECT market, COUNT(*) as cnt
  FROM us_symbol_master
  WHERE status='ACTIVE'
  GROUP BY market;
"
```

### Step 3: 과거 데이터 대량 수집 (Bulk Collection)

**목적**: 모든 종목의 과거 가격 데이터와 지표를 병렬로 수집

**주의사항**:
- 전체 종목 수집 시 **30분-1시간 소요** (약 11,000개 종목)
- FDR rate limiting 적용됨
- 실패한 종목은 `logs/us_bulk_update_failed.log`에 기록
- 일부 소형주/SPAC 종목은 데이터가 없을 수 있음

#### 옵션별 실행 예시

```bash
# 3-1. NASDAQ만, 최근 1년 수집 (추천 시작)
python apps/ingest-databatcher/scripts/us_bulk_update.py \
  --start 2025-01-01 \
  --end 2025-12-31 \
  --market NASDAQ \
  --workers 4 \
  --with-indicators

# 3-2. NYSE만, 병렬 8개
python apps/ingest-databatcher/scripts/us_bulk_update.py \
  --start 2025-01-01 \
  --end 2025-12-31 \
  --market NYSE \
  --workers 8 \
  --with-indicators

# 3-3. 전체 시장 (NYSE + NASDAQ + ETF)
python apps/ingest-databatcher/scripts/us_bulk_update.py \
  --start 2025-01-01 \
  --end 2025-12-31 \
  --workers 8 \
  --with-indicators

# 3-4. symbol 정렬 기준 상위 100개만 (테스트/프로토타입)
python apps/ingest-databatcher/scripts/us_bulk_update.py \
  --start 2025-01-01 \
  --end 2025-12-31 \
  --top 100 \
  --workers 4 \
  --with-indicators

# 3-5. 5년치 과거 데이터 (프로덕션)
python apps/ingest-databatcher/scripts/us_bulk_update.py \
  --start 2020-01-01 \
  --end 2025-12-31 \
  --workers 8 \
  --with-indicators
```

#### Workers 수 조정 가이드

- `--workers 4`: 안정적 (권장)
- `--workers 8`: 빠름 (네트워크 양호 시)
- `--workers 16`: 매우 빠름 (rate limit 주의)

## 4. 정규 운영 방법

### 4.1. 주간 작업: 종목 마스터 동기화

**실행 주기**: 매주 1회 (일요일 새벽 권장)

```bash
# 기본 (yfinance sector 포함, ~1시간)
python apps/ingest-databatcher/scripts/us_sync_symbol_master.py

# 빠른 실행 (종목 리스트만, 1-2분)
python apps/ingest-databatcher/scripts/us_sync_symbol_master.py --skip-yfinance
```

**목적**: 신규 상장 종목 추가, 상장폐지 종목 표시, sector/industry 정보 수집

---

### 4.2. 일일 작업: 데이터 업데이트

**실행 주기**: 매 영업일 US 장마감 후 (한국시간 기준 오전 6-7시)

> **참고**: US 시장 마감 시간
> - 정규장: 16:00 ET (동부 시간)
> - 서머타임 시: 한국시간 오전 5시
> - 비서머타임 시: 한국시간 오전 6시

```bash
# 전체 종목 업데이트
python apps/ingest-databatcher/scripts/us_daily_update.py --all --with-indicators --force

# 또는 특정 마켓만
python apps/ingest-databatcher/scripts/us_daily_update.py --all --market NASDAQ --with-indicators --force
```

**동작 방식**:
1. 최근 50일 가격 데이터 수집 (INSERT ONLY - 기존 데이터 보존)
2. 기본 end date 규칙: ET 18:00 이상이면 ET 오늘, 미만이면 ET 어제
3. 지표 계산 및 저장 (INSERT ONLY)

---

### 4.3. 재수집 (Backfill)

특정 기간의 데이터를 다시 채우려면 `us_bulk_update.py`를 사용합니다.

```bash
# 전체 종목, 특정 기간 재수집
python apps/ingest-databatcher/scripts/us_bulk_update.py \
  --start 2024-01-01 \
  --end 2024-12-31 \
  --workers 4 \
  --with-indicators

# 특정 마켓만
python apps/ingest-databatcher/scripts/us_bulk_update.py \
  --start 2024-01-01 \
  --end 2024-12-31 \
  --market NASDAQ \
  --workers 4 \
  --with-indicators
```

**중요**: `us_bulk_update.py`는 **INSERT ONLY 모드**로 동작합니다. 기존 데이터는 덮어쓰지 않습니다.

## 6. 설정 시스템

**apps/ingest-databatcher/config/settings.yaml**의 `indicators_us` 섹션:

```yaml
indicators_us:
  materialization:
    mode: long
    table_long: us_stock_indicators

  pipeline:
    - name: sma
      params: { window: 5, column: close }
      save: true
    - name: sma
      params: { window: 20, column: close }
      save: true
    - name: ema
      params: { window: 12, column: close }
      save: true
    - name: ema
      params: { window: 26, column: close }
      save: true
```

## 8. FAQ 및 트러블슈팅

### Q1. FDR 데이터 수집 실패

**원인**:
- 네트워크 문제
- FDR 서비스 일시 장애
- 특정 종목 데이터 없음 (소형주, SPAC 등)

**해결**:
```bash
# 1. FDR API 동작 확인
python apps/ingest-databatcher/scripts/probes/fdr_us_stock_probe.py --symbol AAPL

# 2. 특정 종목 수동 테스트
python -c "
import FinanceDataReader as fdr
df = fdr.DataReader('AAPL', '2025-01-01', '2025-01-31')
print(df.head() if df is not None else 'Failed')
"

# 3. workers 수 줄이기
python apps/ingest-databatcher/scripts/us_bulk_update.py --start 2025-01-01 --end 2025-12-31 --workers 2 --with-indicators
```

### Q2. 'date' KeyError 발생

**원인**: FDR 반환 데이터의 인덱스명 불일치

**해결**: `collectors/us_stock.py`에서 컬럼 매핑 확인
```python
column_mapping = {
    'index': 'date',  # reset_index() 후 인덱스명
    'Date': 'date',   # fallback
    ...
}
```

---

### Q3. 소형주/SPAC 데이터 없음

**원인**: FDR에서 일부 소형주, SPAC 종목은 데이터를 제공하지 않음

**해결**:
- `logs/us_bulk_update_failed.log`에서 실패 종목 확인
- 대형주 위주로 수집하거나 실패 종목 무시
- 필요시 Yahoo Finance 등 대체 소스 검토

### Q4. 시간대 관련 이슈

**원인**: US Eastern 시간 계산 오류

**확인**:
```python
from datetime import datetime
try:
    from zoneinfo import ZoneInfo
    us_eastern = ZoneInfo("America/New_York")
except ImportError:
    import pytz
    us_eastern = pytz.timezone("America/New_York")

now_et = datetime.now(us_eastern)
print(f"US Eastern: {now_et}")
```

**해결**: `zoneinfo` 또는 `pytz` 라이브러리 설치 확인

## 11. IBD RS Rating / RS Line / Blue Dot 지표

### 개요

IBD/O'Neil 스타일의 상대강도 지표 3종을 배치 스크립트로 계산합니다.
기존 per-symbol 파이프라인(SMA, EMA)과 달리 전 종목 횡단면(cross-sectional) 계산이 필요하므로 별도 스크립트로 실행합니다.

| 지표 | 설명 | 저장 테이블 |
|------|------|------------|
| `ibd_rs_rating` | 전 종목 대비 상대강도 백분위 순위 (1~99) | us_stock_indicators |
| `rs_line` | 개별 종목 종가 / S&P 500 종가 비율 | us_stock_indicators |
| `blue_dot` | RS Line 52주 신고가 & 주가는 미신고가 시그널 (0/1) | us_stock_indicators |

### 실행 방법

```bash
# us_daily_update.py 실행 후에 RS 지표 계산
python apps/ingest-databatcher/scripts/us_daily_update.py --all --with-indicators
python apps/ingest-databatcher/scripts/us_rs_update.py --force

# 최근 5일만 테스트
python apps/ingest-databatcher/scripts/us_rs_update.py --days 5 --force

# NASDAQ만 대상
python apps/ingest-databatcher/scripts/us_rs_update.py --market NASDAQ --days 30 --force

# 12개월 미만 종목 포함
python apps/ingest-databatcher/scripts/us_rs_update.py --no-strict-12m --force
```

### 인자

| 인자 | 설명 | 기본값 |
|------|------|--------|
| `--end` | 기준 종료일 (YYYY-MM-DD) | US Eastern 어제 |
| `--days` | 저장 대상 일수 | 30 |
| `--market` | NYSE/NASDAQ/ETF/ALL | ALL |
| `--force` | 마감 체크 무시 | - |
| `--strict-12m` | 12개월 미만 종목 제외 | config 값 (true) |
| `--no-strict-12m` | 12개월 미만 종목 포함 | - |

### Cron 예시

```bash
# 평일 07:05 KST (us_daily_update 완료 후)
5 7 * * 1-5 cd /path/to/DataBatcher && source .venv/bin/activate && python apps/ingest-databatcher/scripts/us_rs_update.py --force >> logs/us_rs_update.log 2>&1
```

### DB 검증

```sql
-- RS Rating 분포 확인 (1~99 범위)
SELECT symbol, date, indicator, value
FROM us_stock_indicators
WHERE indicator = 'ibd_rs_rating'
ORDER BY date DESC, value DESC
LIMIT 20;

-- RS Line 확인
SELECT symbol, date, value
FROM us_stock_indicators
WHERE indicator = 'rs_line' AND symbol = 'AAPL'
ORDER BY date DESC LIMIT 10;

-- Blue Dot 시그널 (value=1)
SELECT symbol, date, value
FROM us_stock_indicators
WHERE indicator = 'blue_dot' AND value = 1
ORDER BY date DESC LIMIT 20;
```
