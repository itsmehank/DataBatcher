# 미너비니 트렌드 템플릿 (Minervini Trend Template) 가이드

## 개요

Mark Minervini의 **트렌드 템플릿(Trend Template)** 조건을 사전 배치로 계산하여 `minervini_screen_results_kr` / `minervini_screen_results_us` 테이블에 저장합니다. Grafana에서 수만 개 종목에 대해 실시간 계산하는 부하를 방지하기 위해, 일일 배치로 조건을 만족하는 종목만 사전 적재합니다.

**지원 시장**:
- 한국 주식: KOSPI, KOSDAQ, ETF
- 미국 주식: NYSE, NASDAQ, ETF

---

## 미너비니 트렌드 템플릿이란?

Mark Minervini의 트렌드 템플릿은 강력한 상승 추세에 있는 종목을 선별하기 위한 8가지 조건입니다:

### 8가지 핵심 조건

1. **현재 주가 > 150일 이동평균선**
2. **현재 주가 > 200일 이동평균선**
3. **150일 이동평균선 > 200일 이동평균선**
4. **200일 이동평균선 상승 추세** (최소 1개월, 22거래일 전보다 높음)
5. **50일 이동평균선 > 150일 이동평균선**
6. **50일 이동평균선 > 200일 이동평균선**
7. **현재 주가 >= 52주 최저가 × 1.3** (52주 저가 대비 최소 30% 이상)
8. **현재 주가 >= 52주 최고가 × 0.75** (52주 고가의 최소 75% 이상)

### 추가 필터 (IBD 방식)

- **RS Rating >= 80**: IBD Relative Strength Rating (1~99 백분위)
- **Blue Dot** (선택적, 기본값: False): RS Line이 52주 신고가이면서 주가는 신고가가 아닌 경우

---

## 스크리닝 조건 상세

### 1. MA 정배열 (MA Ordering)
`price > sma50 > sma150 > sma200`

- 현재 주가가 모든 주요 이동평균선(50/150/200) 위에 있음
- 이동평균선들이 상승 정배열을 이룸 (짧은 MA > 긴 MA)

### 2. SMA200 상승 추세 (SMA200 Uptrend)
`sma200 > sma200.shift(22)`

- 200일 이동평균선이 22거래일(약 1개월) 전보다 높음
- 장기 추세가 상승 국면임을 확인

### 3. 52주 저가 대비 가격 위치 (Price Above 52W Low)
`price >= low_52w * 1.3`

- 현재 주가가 52주 최저가 대비 최소 30% 이상 상승
- 바닥권에서 어느 정도 벗어난 종목 선별

### 4. 52주 고가 근접도 (Price Near 52W High)
`price >= high_52w * 0.75`

- 현재 주가가 52주 최고가의 최소 75% 이상
- 고가권에서 거래되는 강세 종목 선별

### 5. RS Rating (IBD Relative Strength)
`rs_rating >= 80`

- IBD 방식 상대 강도 백분위 (1~99)
- 3/6/9/12개월 수익률 가중 합산 후 횡단면 백분위 계산
- 80 이상: 상위 20% 이내 종목

### 6. Blue Dot (선택적)
`blue_dot == 1`

- RS Line(주가/지수비율)이 52주 신고가이면서 주가는 신고가가 아닌 경우
- 상대적 강도는 신고가인데 절대 가격은 아직 고가 갱신 전 → 곧 돌파 가능성

## 실행 방법

### 전제 조건

1. **가격 데이터 수집 완료**: `bulk_update.py` / `us_bulk_update.py` 실행
2. **RS 지표 계산 완료**: `kr_rs_update.py` / `us_rs_update.py` 실행 (RS Rating, Blue Dot)
3. **DB에 최소 252거래일(52주) 이상의 가격 데이터 필요**

### 전체 백필 (Initial Setup)

```bash
# 한국 주식 - 전체 기간 백필
python apps/ingest-databatcher/scripts/kr_minervini_update.py --days 9999 --force

# 미국 주식 - 전체 기간 백필
python apps/ingest-databatcher/scripts/us_minervini_update.py --days 9999 --force
```

**예상 소요 시간**: 5-10분 (전체 종목, 전체 기간)

### 일일 업데이트 (Daily Routine)

```bash
# 한국 주식 - 최근 7일
python apps/ingest-databatcher/scripts/kr_minervini_update.py --days 7 --force

# 미국 주식 - 최근 7일
python apps/ingest-databatcher/scripts/us_minervini_update.py --days 7 --force
```

**예상 소요 시간**: 1-2분

### 특정 마켓만 처리

```bash
# KOSPI만
python apps/ingest-databatcher/scripts/kr_minervini_update.py --market KOSPI --days 30 --force

# NASDAQ만
python apps/ingest-databatcher/scripts/us_minervini_update.py --market NASDAQ --days 30 --force
```

### CLI 옵션

| 옵션 | 설명 | 기본값 |
|------|------|--------|
| `--end` | 기준 종료일 (YYYY-MM-DD) | 마지막 영업일 |
| `--days` | 저장 대상 일수 (최근 N 거래일) | 30 |
| `--market` | 대상 마켓 (KR: KOSPI/KOSDAQ/ETF/ALL, US: NYSE/NASDAQ/ETF/ALL) | ALL |
| `--force` | 마감/버퍼 체크 무시 | False |

## 설정 파일 (apps/ingest-databatcher/config/settings.yaml)

### 한국 주식 설정 (`minervini_kr`)

```yaml
minervini_kr:
  filters:
    ma_ordering:
      enabled: true                # price > sma50 > sma150 > sma200
    sma200_uptrend:
      enabled: true
      lookback: 22                 # 200일선이 22거래일 전보다 높음
    price_above_52w_low:
      enabled: true
      pct: 1.3                     # 52주 저가 대비 130% 이상
    price_near_52w_high:
      enabled: true
      pct: 0.75                    # 52주 고가의 75% 이상
    rs_rating:
      enabled: true
      min: 80                      # RS Rating 80 이상
    blue_dot:
      enabled: false               # Blue Dot 필터 (선택적)
  lookback_52w: 252                # 52주 = 252 거래일
```

### 미국 주식 설정 (`minervini_us`)

동일한 구조 (한국/미국 시장별 차별화 가능)

### 필터 활성화/비활성화

각 필터는 `enabled: true/false`로 개별 제어 가능:

```yaml
filters:
  ma_ordering:
    enabled: false  # MA 정배열 조건 제외
  rs_rating:
    enabled: true
    min: 80         # RS Rating 기준을 80으로 상향
```

## 데이터 의존성

```
stock_prices / us_stock_prices (가격 데이터)
    ↓
kr_rs_update / us_rs_update (RS Rating, Blue Dot 계산)
    ↓
kr_minervini_update / us_minervini_update (스크리닝)
```

**중요**: RS Rating/Blue Dot가 아직 계산되지 않은 경우:
- 해당 필터를 건너뛰고 경고 메시지 출력
- 에러로 중단하지 않음 (다른 필터만으로도 스크리닝 가능)

## 데이터베이스 테이블

### `minervini_screen_results_kr`

| 컬럼 | 타입 | 설명 |
|------|------|------|
| `symbol` | VARCHAR(32) | 종목 코드 |
| `date` | DATE | 스크리닝 날짜 |
| `market` | VARCHAR(16) | 시장 (KOSPI/KOSDAQ/ETF) |
| `rs_rating` | DECIMAL(5,1) | IBD RS Rating (1~99) |
| `is_blue_dot` | TINYINT | Blue Dot 신호 (0/1) |
| `screen_config_hash` | CHAR(40) | 스크리닝 설정 해시 |
| `failed_reason` | VARCHAR(512) | 탈락 사유 (미사용, NULL) |
| `created_at` | TIMESTAMP | 레코드 생성 시각 |

**PK**: `(symbol, date, screen_config_hash)`

### `minervini_screen_results_us`

동일한 구조 (market: NYSE/NASDAQ/ETF)

### 저장 방식

- **통과 종목만 저장**: 조건을 만족한 종목만 INSERT (탈락 종목은 저장하지 않음)
- **INSERT ONLY 모드**: 기존 데이터 보존, 중복 실행 안전
- **설정 해시 기반 공존**: 필터 설정이 달라지면 별도 행으로 저장 가능

## Grafana 활용

### 기본 쿼리 (특정 날짜)

```sql
SELECT
  symbol,
  market,
  rs_rating,
  is_blue_dot
FROM minervini_screen_results_kr
WHERE date = '2026-02-07'
  AND screen_config_hash = 'abc123...'  -- 현재 설정 해시
ORDER BY rs_rating DESC
LIMIT 50;
```

### 최신 날짜 자동 조회

```sql
SELECT
  m.symbol,
  m.market,
  m.rs_rating,
  m.is_blue_dot,
  sm.name,
  sm.sector
FROM minervini_screen_results_kr m
JOIN symbol_master sm ON m.symbol = sm.symbol
WHERE m.date = (SELECT MAX(date) FROM minervini_screen_results_kr)
ORDER BY m.rs_rating DESC
LIMIT 100;
```

### Blue Dot 종목만 필터

```sql
SELECT
  symbol,
  market,
  rs_rating
FROM minervini_screen_results_us
WHERE date = (SELECT MAX(date) FROM minervini_screen_results_us)
  AND is_blue_dot = 1
ORDER BY rs_rating DESC;
```

### 일별 통과 종목 수 추이

```sql
SELECT
  date,
  market,
  COUNT(*) as pass_count
FROM minervini_screen_results_kr
WHERE date >= DATE_SUB(CURDATE(), INTERVAL 30 DAY)
GROUP BY date, market
ORDER BY date DESC, market;
```

## 트러블슈팅

### "Error: 가격 데이터 없음"

**원인**: DB에 가격 데이터가 없거나 로드 기간이 부족

**해결**:
```bash
# 가격 데이터 수집
python apps/ingest-databatcher/scripts/bulk_update.py --start 2024-01-01 --end 2024-12-31 --workers 4
python apps/ingest-databatcher/scripts/us_bulk_update.py --start 2024-01-01 --end 2024-12-31 --workers 4
```

### "Warning: RS Rating 데이터 없음"

**원인**: RS Rating이 아직 계산되지 않음

**해결**:
```bash
# RS Rating 계산
python apps/ingest-databatcher/scripts/kr_rs_update.py --days 9999 --force
python apps/ingest-databatcher/scripts/us_rs_update.py --days 9999 --force
```

**참고**: RS Rating 필터가 비활성화되어 있다면 경고만 출력하고 계속 진행됨

### "Warning: 통과한 종목 없음"

**원인**: 모든 종목이 스크리닝 조건을 만족하지 못함

**해결**:
- 필터 조건 완화 (apps/ingest-databatcher/config/settings.yaml 수정)
- 특히 `rs_rating.min`을80 → 70으로 낮춤
- 또는 `blue_dot.enabled`를 `false`로 설정

### 성능 최적화

- **전체 백필 시**: `--days 9999`로 한 번에 처리 (5-10분)
- **일일 업데이트**: `--days 7`로 최근 데이터만 처리 (1-2분)
- **마켓 분할**: 큰 시장은 별도 실행 (`--market KOSPI`, `--market NASDAQ`)
