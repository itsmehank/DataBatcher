## 개요

### 목적

`manage_table.py`는 DataBatcher 프로젝트의 MySQL 테이블을 안전하고 효율적으로 관리하기 위한 통합 도구입니다.

### 주요 기능

- ✅ **테이블 삭제** (DROP TABLE)
- ✅ **테이블 데이터 삭제** (TRUNCATE, 구조는 유지)
- ✅ **특정 종목 데이터 삭제** (DELETE by symbol)
- ✅ **조건부 데이터 삭제** (DELETE with conditions)

### 안전 장치

- 🛡️ **확인 프롬프트**: 모든 위험한 작업 전 사용자 확인
- 🧪 **Dry-run 모드**: 실제 실행 전 SQL 미리보기
- 📊 **행 수 사전 확인**: 삭제 전 영향받을 행 수 표시
- 🔐 **트랜잭션 보호**: 작업 실패 시 자동 롤백

## 명령어 레퍼런스

### 1. drop - 테이블 삭제

**용도**: 테이블 전체를 삭제합니다 (구조 + 데이터).

**문법**:
```bash
python scripts/table_manipulate/manage_table.py drop --table [테이블명] [옵션]
```

**필수 인자**:
- `--table`: 삭제할 테이블 이름

**선택 인자**:
- `--yes`: 확인 프롬프트 생략
- `--dry-run`: SQL만 출력 (실행 안 함)

**실행 SQL**:
```sql
DROP TABLE IF EXISTS [테이블명]
```

**예시**:
```bash
# Dry-run으로 먼저 확인
python scripts/table_manipulate/manage_table.py drop --table stock_prices --dry-run

# 실제 실행 (확인 프롬프트 표시)
python scripts/table_manipulate/manage_table.py drop --table stock_prices

# 확인 없이 즉시 실행
python scripts/table_manipulate/manage_table.py drop --table stock_prices --yes
```

**출력 예시**:
```
⚠️ DROP table 'stock_prices'? (yes/no): yes
✅ Table 'stock_prices' dropped successfully.
```

---

### 2. truncate - 테이블 데이터 삭제 (구조 유지)

**용도**: 테이블의 모든 데이터를 삭제하되, 테이블 구조는 유지합니다.

**문법**:
```bash
python scripts/table_manipulate/manage_table.py truncate --table [테이블명] [옵션]
```

**필수 인자**:
- `--table`: 비울 테이블 이름

**선택 인자**:
- `--yes`: 확인 프롬프트 생략
- `--dry-run`: SQL만 출력 (실행 안 함)

**실행 SQL**:
```sql
TRUNCATE TABLE [테이블명]
```

**예시**:
```bash
# Dry-run으로 SQL 확인
python scripts/table_manipulate/manage_table.py truncate --table stock_indicators --dry-run

# 실제 실행
python scripts/table_manipulate/manage_table.py truncate --table stock_indicators
```

```bash

python scripts/table_manipulate/manage_table.py truncate --table trade.stock_prices --yes

python scripts/table_manipulate/manage_table.py truncate --table trade.stock_prices_weekly --yes

python scripts/table_manipulate/manage_table.py truncate --table trade.stock_indicators --yes

python scripts/table_manipulate/manage_table.py truncate --table trade.stock_indicators_weekly --yes


```

**출력 예시**:
```
⚠️ TRUNCATE table 'stock_indicators'? (yes/no): yes
✅ Table 'stock_indicators' truncated successfully.
```

**drop vs truncate 비교**:

| 작업 | DROP | TRUNCATE |
|------|------|----------|
| 테이블 구조 | 삭제됨 | 유지됨 |
| 데이터 | 삭제됨 | 삭제됨 |
| 인덱스 | 삭제됨 | 유지됨 |
| 복구 | `init_db.py` 재실행 필요 | 데이터 재적재만 필요 |
| 속도 | 빠름 | 매우 빠름 |

### 3. delete-symbol - 특정 종목 데이터 삭제

**용도**: 특정 symbol(종목 코드)의 모든 행을 삭제합니다.

**문법**:
```bash
python scripts/table_manipulate/manage_table.py delete-symbol \
  --table [테이블명] \
  --symbol [종목코드] \
  [옵션]
```

**필수 인자**:
- `--table`: 테이블 이름
- `--symbol`: 종목 코드 (예: `005930`)

**선택 인자**:
- `--yes`: 확인 프롬프트 생략
- `--dry-run`: 삭제될 행 수만 확인

**실행 SQL**:
```sql
-- 먼저 행 수 확인
SELECT COUNT(*) FROM [테이블명] WHERE symbol = '[종목코드]'

-- 실제 삭제
DELETE FROM [테이블명] WHERE symbol = '[종목코드]'
```

**예시**:
```bash
# 삼성전자(005930) 데이터 삭제 - Dry-run
python scripts/table_manipulate/manage_table.py delete-symbol \
  --table stock_prices \
  --symbol 005930 \
  --dry-run

# 실제 삭제
python scripts/table_manipulate/manage_table.py delete-symbol \
  --table stock_prices \
  --symbol 005930
```

**출력 예시**:
```
⚠️ DELETE all rows for symbol '005930' from 'stock_prices'? (yes/no): yes
✅ Deleted 252 rows for symbol '005930' from 'stock_prices'.
```

**데이터 없을 때**:
```
⚠️ No rows found for symbol '005930' in 'stock_prices'.
```

### 4. delete-rows - 조건부 데이터 삭제

**용도**: 특정 symbol과 특정 컬럼 값 조건에 맞는 행만 삭제합니다.

**문법**:
```bash
python scripts/table_manipulate/manage_table.py delete-rows \
  --table [테이블명] \
  --symbol [종목코드] \
  --column [컬럼명] \
  --value [값] \
  [옵션]
```

**필수 인자**:
- `--table`: 테이블 이름
- `--symbol`: 종목 코드
- `--column`: 조건 컬럼명 (예: `indicator`)
- `--value`: 조건 값 (예: `sma_5_close`)

**선택 인자**:
- `--yes`: 확인 프롬프트 생략
- `--dry-run`: 삭제될 행 수만 확인

**실행 SQL**:
```sql
-- 먼저 행 수 확인
SELECT COUNT(*) FROM [테이블명] 
WHERE symbol = '[종목코드]' AND [컬럼명] = '[값]'

-- 실제 삭제
DELETE FROM [테이블명] 
WHERE symbol = '[종목코드]' AND [컬럼명] = '[값]'
```

**예시**:
```bash
# 삼성전자의 SMA 5일 지표만 삭제 - Dry-run
python scripts/table_manipulate/manage_table.py delete-rows \
  --table stock_indicators \
  --symbol 005930 \
  --column indicator \
  --value sma_5_close \
  --dry-run

# 실제 삭제
python scripts/table_manipulate/manage_table.py delete-rows \
  --table stock_indicators \
  --symbol 005930 \
  --column indicator \
  --value sma_5_close
```

**출력 예시**:
```
⚠️ DELETE rows where symbol='005930' AND indicator='sma_5_close' from 'stock_indicators'? (yes/no): yes
✅ Deleted 252 rows for symbol='005930' AND indicator='sma_5_close' from 'stock_indicators'.
```

**동작**:

**예시**:

```bash
  --dry-run

```

**dry-run 시 행 수 표시**:
```bash
python scripts/table_manipulate/manage_table.py delete-symbol \
  --table stock_prices \
  --symbol 005930 \
  --dry-run

# 출력:
[DRY-RUN] DELETE FROM stock_prices WHERE symbol = :symbol (will delete 252 rows)
```

### 4. 트랜잭션 보호

**동작**:
- 모든 작업은 트랜잭션 내에서 실행 (`engine.begin()`)
- 작업 중 에러 발생 시 자동 롤백
- 데이터 일관성 보장

**코드 구조**:
```python
with engine.begin() as conn:
    conn.execute(text(sql))  # 성공 시 자동 커밋, 실패 시 롤백
```

---

### 5. SQL Injection 방지

**보호 방법**:
- SQLAlchemy의 parameterized query 사용
- 사용자 입력을 직접 SQL 문자열에 삽입하지 않음

**안전한 쿼리 예시**:
```python
# ❌ 위험 (SQL Injection 가능)
sql = f"DELETE FROM {table} WHERE symbol = '{symbol}'"

# ✅ 안전 (Parameterized query)
sql = f"DELETE FROM {table} WHERE symbol = :symbol"
conn.execute(text(sql), {"symbol": symbol})
```

## FAQ

### Q1: `drop`과 `truncate`의 차이는?

**A**: 
- `drop`: 테이블 **구조까지 삭제**. 재생성 필요 (`init_db.py`)
- `truncate`: **데이터만 삭제**, 구조 유지. 데이터 재적재만 필요

**권장 사용**:
- 테스트 데이터 정리 → `truncate`
- 테이블 스키마 변경 후 재생성 → `drop` + `init_db.py`

### Q2: 여러 종목을 한번에 삭제할 수 있나?

**A**: 현재 스크립트는 한 번에 한 종목만 지원. 여러 종목 삭제 시 반복문 사용:

```bash
# Bash 반복문
for symbol in 005930 000660 035720; do
  python scripts/table_manipulate/manage_table.py delete-symbol \
    --table stock_prices \
    --symbol $symbol \
    --yes
done
```

---

### Q3: 삭제 전 백업하는 방법은?

**A**: `mysqldump` 사용:

```bash
# 특정 종목 백업
mysqldump -h 127.0.0.1 -u USER -p'<password>' trade \
  --where="symbol='005930'" \
  stock_prices stock_indicators > backup_005930.sql

# 전체 테이블 백업
mysqldump -h 127.0.0.1 -u USER -p'<password>' trade stock_prices > backup_stock_prices.sql

# 복원
mysql -h 127.0.0.1 -u USER -p'<password>' trade < backup_005930.sql
```

---

### Q4: 실수로 삭제한 데이터 복구 방법은?

**A**: 
1. **백업에서 복원** (백업이 있는 경우)
2. **재수집** (bulk_update.py 또는 daily_update.py)

```bash
# 재수집 예시
python scripts/bulk_update.py --start 2024-01-01 --end 2024-12-31 --symbols 005930
```

**예방**:
- 항상 `--dry-run`으로 먼저 확인
- 중요 작업 전 백업 수행

---

### Q5: View도 삭제할 수 있나?

**A**: 현재 스크립트는 테이블만 지원. View 삭제는 SQL 직접 실행:

```sql
DROP VIEW IF EXISTS v_stock_price_with_ma;

-- 또는 재생성
python scripts/init_db.py  -- View가 CREATE OR REPLACE로 정의되어 자동 갱신
```

---

### Q6: 프로덕션 환경에서 사용해도 안전한가?

**A**: 
- ✅ **안전 장치**: 확인 프롬프트, dry-run, 트랜잭션 보호
- ⚠️ **주의사항**: 
  - 반드시 `--dry-run`으로 먼저 테스트
  - 중요 데이터는 백업 후 작업
  - 피크 시간대 피하기 (대량 삭제 시)

---

### Q7: 날짜 범위로 삭제할 수 있나?

**A**: 현재 미지원. 향후 추가 예정 기능:

```bash
# 향후 예정 (현재 불가)
python scripts/table_manipulate/manage_table.py delete-date-range \
  --table stock_prices \
  --start 2024-01-01 \
  --end 2024-01-31
```

**현재 해결 방법**: SQL 직접 실행

```bash
mysql -h 127.0.0.1 -u USER -p'<password>' trade -e \
  "DELETE FROM stock_prices WHERE date BETWEEN '2024-01-01' AND '2024-01-31'"
```
