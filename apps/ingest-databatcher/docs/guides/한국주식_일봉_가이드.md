# DataBatcher 실행 가이드 (Korean)

본 문서는 DataBatcher 프로젝트를 로컬/서버 환경에서 실행하기 위한 단계별 안내서입니다.

**최종 업데이트**: 2026-01-19 (INSERT ONLY 모드, Smart Daily Updates 적용)

> 문서 해석 주의: `--top N`은 현재 코드에서 **시가총액 상위 N개가 아니라, symbol 정렬 기준 상위 N개**를 의미합니다.

## 프로젝트 개요

DataBatcher는 한국 주식시장 데이터 수집 및 기술적 지표 계산 시스템입니다.
> 2026-02 업데이트: **ETF(상장지수펀드)도 동일한 파이프라인(symbol_master → stock_prices → stock_indicators)에 포함**됩니다.
> - symbol_master에 `market = 'ETF'`로 저장된 종목은, 별도의 테이블을 쓰지 않고 기존 `stock_prices` / `stock_indicators`에 적재됩니다.
> - `--market KOSPI`처럼 시장 필터를 주면 **ETF는 제외**됩니다. ETF를 포함하려면 `--market ALL`(기본값) 또는 `--market ETF`를 사용하세요.

**핵심 파이프라인**: 데이터 수집(collectors) → 지표 계산(indicators) → DB 저장(savers)

## 1. 사전 요구사항

- **Python 3.10+** 권장 (3.9 이상 동작 가능)
- **pip** 또는 pipx
- **Docker + Docker Compose** (로컬 MySQL 실행 용도, 권장)
- **MySQL 8.0+** (Docker 사용 또는 별도 설치)

## 2. 최초 설치 및 실행 (Quick Start)

처음 시작하는 경우, 다음 4단계로 빠르게 시작할 수 있습니다.

**예상 소요 시간**: 5-10분

```bash
# 1. 가상환경 활성화 및 의존성 설치
source .venv/bin/activate  # 또는 .venv\Scripts\activate (Windows)
pip install -r requirements.txt

# 2. Docker MySQL 실행 및 DB 초기화
cd docker && docker compose up -d && cd ..
python apps/ingest-databatcher/scripts/init_db.py

# 3. 종목 마스터 동기화 (약 2,900개 종목)
python apps/ingest-databatcher/scripts/sync_symbol_master.py

# 4. 테스트 데이터 수집 (symbol 정렬 기준 상위 100개, 최근 1년)
python apps/ingest-databatcher/scripts/bulk_update.py --start 2024-01-01 --end 2024-12-31 --top 100 --workers 4

# 5. 일일 업데이트 테스트 (상위 10개 종목)
python apps/ingest-databatcher/scripts/daily_update.py --all --top 10 --force
```

### Step 3: 과거 데이터 대량 수집 (Bulk Collection)

**목적**: 모든 종목의 과거 가격 데이터와 지표를 병렬로 수집

**주의사항**:
- 전체 종목 수집 시 **10-30분 소요**
- pykrx API rate limiting 적용됨
- 실패한 종목은 `logs/bulk_update_failed.log`에 기록

#### 옵션별 실행 예시

```bash

  --start 2024-01-01 \
  --end 2024-12-31 \
  --workers 4

# 3-2. KOSPI만 수집 (ETF 제외, 빠른 테스트)
python apps/ingest-databatcher/scripts/bulk_update.py \
  --start 2024-01-01 \
  --end 2024-12-31 \
  --market KOSPI \
  --workers 4

# 3-2b. ETF만 수집
python apps/ingest-databatcher/scripts/bulk_update.py \
  --start 2024-01-01 \
  --end 2024-12-31 \
  --market ETF \
  --workers 4

# 3-3. symbol 정렬 기준 상위 100개만 수집 (프로토타입)

  --end 2024-12-31 \
```

## 4. 정규 운영 방법

### 4.1. 주간 작업: 종목 마스터 동기화

**실행 주기**: 매주 1회 (일요일 새벽 권장)

```bash
python apps/ingest-databatcher/scripts/sync_symbol_master.py
```

**목적**: 신규 상장 종목 추가, 상장폐지 종목 표시

---

### 4.2. 일일 작업: 데이터 업데이트

**실행 주기**: 매 영업일 장마감 30분 후 (평일 16:30 이후)

```bash
# 전체 종목 업데이트
python apps/ingest-databatcher/scripts/daily_update.py --all --force

# 또는 특정 마켓만
python apps/ingest-databatcher/scripts/daily_update.py --all --market KOSPI --force
```

**동작 방식** (2026-01-19 개선 버전):
1. 최근 30일 가격 데이터 수집 (INSERT ONLY - 기존 데이터 보존)
2. DB에서 250일 가격 데이터 조회
3. 250일치 전체에 대해 지표 계산
4. 최신 날짜부터 역순 처리:
   - 모든 지표가 완료된 날짜 만나면 중단 (조기 종료)
   - 누락된 날짜만 지표 INSERT ONLY

---

### 4.3. 재수집 (Backfill)

특정 기간(예: 과거 누락 구간)의 데이터를 다시 채우려면, 현재 코드 기준으로는 **`bulk_update.py`를 사용하는 것이 정석**입니다.

```bash
# 전체 종목, 특정 기간 재수집 (권장)
python apps/ingest-databatcher/scripts/bulk_update.py --start 2023-01-01 --end 2023-12-31 --workers 4

# 특정 마켓만
python apps/ingest-databatcher/scripts/bulk_update.py --start 2023-01-01 --end 2023-12-31 --market KOSPI --workers 4

# 상위 N개만(테스트)
python apps/ingest-databatcher/scripts/bulk_update.py --start 2023-01-01 --end 2023-12-31 --top 100 --workers 4
```

**중요**:
- `bulk_update.py`는 **INSERT ONLY 모드**로 동작합니다. 즉, 기존 데이터는 덮어쓰지 않고 **없는 날짜만 채웁니다**.
- 기존 데이터까지 “다시 계산/교체”가 필요하면 `insert_only`가 아닌 별도 재동기화 스크립트(또는 테이블 삭제 후 재적재)가 필요합니다.

#### daily_update.py의 --start/--end 동작(현행 코드 기준)

- `daily_update.py`는 “일일 증분 + 지표 누락분만 역방향 INSERT ONLY” 용도로 설계되어 있습니다.
- 현재 코드에서 `--end`는 기준일로 사용되지만, `--start`는 **가격 수집/지표 계산 범위를 직접 제어하는 용도로 사용되지 않습니다.**
  - 가격 수집: 항상 `end_date` 기준 최근 30일만 INSERT ONLY
  - 지표 계산/저장: 항상 `end_date` 기준 최근 250일 범위에서, 완료된 날짜를 만나면 중단

따라서 **특정 기간 전체를 재수집(backfill)하려는 목적에는 `daily_update.py --start ...` 방식이 맞지 않습니다.**

또한 `--symbols` 모드는 `symbol_master`에서 ACTIVE로 조회되는 종목만 처리합니다.
- `symbol_master`에 없거나 ACTIVE가 아니면 경고 후 스킵됩니다.

## 5. 설정 시스템

### 5.0. 코드 기준 진실 소스(SoT)

문서와 실제 동작이 다를 때는 아래 코드를 기준으로 판단합니다.

- 일일 증분 처리(30일 수집/250일 지표/역순 중단): `apps/ingest-databatcher/scripts/daily_update.py`
- 대량 수집(병렬 workers, --top 동작): `apps/ingest-databatcher/scripts/bulk_update.py`
- 심볼 로딩/필터링(--market, --top): `core/symbol_loader.py`
- DB 저장 정책(insert_only/upsert): `core/db_manager.py`

### 5.1. 설정 로드 우선순위

애플리케이션은 다음 순서로 설정을 로드하며, 상위 항목이 하위 항목을 오버라이드합니다:

```
1순위: 환경변수 DATABASE_URL (최우선, 선택사항)
   ↓ 없으면
2순위: apps/ingest-databatcher/config/settings.dev.yaml (개발 환경용)
   ↓ 없으면
3순위: apps/ingest-databatcher/config/settings.yaml (기본값/운영 환경용)
```

### 5.2. 권장 사용 방식

#### 로컬 개발

`apps/ingest-databatcher/config/settings.dev.yaml`에 설정 → 환경변수 불필요

```bash
# 설정 파일만으로 바로 실행 가능
python apps/ingest-databatcher/scripts/daily_update.py --all --top 10 --force
```

#### 운영 환경

시스템 환경변수 또는 `apps/ingest-databatcher/config/settings.yaml` 사용

```bash
# systemd, supervisor, cron 등에서 환경변수 설정
export DATABASE_URL="mysql+pymysql://user:pass@host:3306/market?charset=utf8mb4"
```

#### 일시적 테스트

터미널에서 환경변수로 오버라이드

```bash
export DATABASE_URL="mysql+pymysql://test:test@localhost:3307/test_db?charset=utf8mb4"
python apps/ingest-databatcher/scripts/daily_update.py --all --top 5 --force
```

### 5.3. 설정 파일 구조

**apps/ingest-databatcher/config/settings.yaml** (공통 기본값):
```yaml
runtime:
  timezone: Asia/Seoul
  rate_limit_per_sec: 5

markets:
  close_times:
    XKRX: "16:00"
  safe_delay_minutes: 30

indicators:
  pipeline:
    - name: sma
      params: { window: 5, column: close }
      save: true
    - name: sma
      params: { window: 20, column: close }
      save: true
    - name: ema
      params: { window: 12, column: close }
      save: true
```

**apps/ingest-databatcher/config/settings.dev.yaml** (개발 환경 오버라이드):
```yaml
database:
  url: mysql+pymysql://YOUR_DB_USER:YOUR_DB_PASSWORD@127.0.0.1:3306/market?charset=utf8mb4
  pool_size: 5
  max_overflow: 10
```

## 6. 자동화 설정

### 6.1. Cron (Linux/Mac)

```bash
# crontab 편집
crontab -e

# 추가할 내용:
# 주간: 일요일 새벽 2시에 종목 마스터 동기화
0 2 * * 0 cd /path/to/DataBatcher && source .venv/bin/activate && python apps/ingest-databatcher/scripts/sync_symbol_master.py >> logs/sync_symbol_master.log 2>&1

# 일일: 평일 오후 5시(장마감 30분 후)에 전체 업데이트
0 17 * * 1-5 cd /path/to/DataBatcher && source .venv/bin/activate && python apps/ingest-databatcher/scripts/daily_update.py --all --force >> logs/daily_update.log 2>&1
```

### 6.2. Systemd (Linux)

**서비스 파일**: `/etc/systemd/system/databatcher-daily.service`

```ini
[Unit]
Description=DataBatcher Daily Update
After=network.target

[Service]
```

## 10. IBD RS Rating / RS Line / Blue Dot 지표

### 개요

IBD/O'Neil 스타일의 상대강도 지표 3종을 배치 스크립트로 계산합니다.
기존 per-symbol 파이프라인(SMA, EMA)과 달리 전 종목 횡단면(cross-sectional) 계산이 필요하므로 별도 스크립트로 실행합니다.

| 지표 | 설명 | 저장 테이블 |
|------|------|------------|
| `ibd_rs_rating` | 전 종목 대비 상대강도 백분위 순위 (1~99) | stock_indicators |
| `rs_line` | 개별 종목 종가 / KOSPI 종가 비율 | stock_indicators |
| `blue_dot` | RS Line 52주 신고가 & 주가는 미신고가 시그널 (0/1) | stock_indicators |

### 실행 방법

```bash
# daily_update.py 실행 후에 RS 지표 계산
python apps/ingest-databatcher/scripts/daily_update.py --all --force
python apps/ingest-databatcher/scripts/kr_rs_update.py --force

# 최근 5일만 테스트
python apps/ingest-databatcher/scripts/kr_rs_update.py --days 5 --force

# KOSPI만 대상
python apps/ingest-databatcher/scripts/kr_rs_update.py --market KOSPI --days 30 --force

# 12개월 미만 종목 포함
python apps/ingest-databatcher/scripts/kr_rs_update.py --no-strict-12m --force
```

### 인자

| 인자 | 설명 | 기본값 |
|------|------|--------|
| `--end` | 기준 종료일 (YYYY-MM-DD) | 마지막 영업일 |
| `--days` | 저장 대상 일수 | 30 |
| `--market` | KOSPI/KOSDAQ/ETF/ALL | ALL |
| `--force` | 마감 체크 무시 | - |
| `--strict-12m` | 12개월 미만 종목 제외 | config 값 (true) |
| `--no-strict-12m` | 12개월 미만 종목 포함 | - |

### Cron 예시

```bash
# 평일 17:05 (daily_update 완료 후)
5 17 * * 1-5 cd /path/to/DataBatcher && source .venv/bin/activate && python apps/ingest-databatcher/scripts/kr_rs_update.py --force >> logs/kr_rs_update.log 2>&1
```

### DB 검증

```sql
-- RS Rating 분포 확인 (1~99 범위)
SELECT symbol, date, indicator, value
FROM stock_indicators
WHERE indicator = 'ibd_rs_rating'
ORDER BY date DESC, value DESC
LIMIT 20;

-- RS Line 확인
SELECT symbol, date, value
FROM stock_indicators
WHERE indicator = 'rs_line' AND symbol = '005930'
ORDER BY date DESC LIMIT 10;

-- Blue Dot 시그널 (value=1)
SELECT symbol, date, value
FROM stock_indicators
WHERE indicator = 'blue_dot' AND value = 1
ORDER BY date DESC LIMIT 20;
```
