# 📋 미너비니 트렌드 템플릿 사전 스크리닝 작업 계획 (v2.0)

## 1. 작업 목적

- **성능 최적화**: Grafana에서 수만 개의 종목 데이터에 대해 52주 고저가 및 이동평균선 조건을 실시간 계산할 때 발생하는 부하를 제거합니다.
- **유연한 스크리닝**: 시장 상황에 따라 기준을 완화/강화할 수 있도록 YAML 기반 설정 파일 시스템을 구축합니다.
- **데이터 자산화**: 특정 시점에 조건을 만족했던 종목을 보관하여 향후 전략 튜닝 및 백테스팅에 활용합니다.

## 2. 데이터베이스 설계 (보완)

계산된 결과를 저장할 테이블에 인덱스와 디버깅용 컬럼을 추가합니다.

- **Table Name**: 
  - 한국 시장 대상: `minervini_screen_results_kr`
  - 미국 시장 대상: `minervini_screen_results_us`
- **Columns**:
  - `symbol` (VARCHAR): 종목 코드
  - `date` (DATE): 기준 일자
  - `market` (VARCHAR): 시장 구분 (NYSE, NASDAQ, KOSPI 등)
  - `rs_rating` (DECIMAL): 해당 시점의 RS 점수 (1~99)
  - `is_blue_dot` (BOOLEAN): Blue Dot 발생 여부 (1: 발생, 0: 미발생)
  - `screen_config_hash` (VARCHAR): 적용된 설정 식별 해시값
  - `failed_reason` (VARCHAR): 필터 탈락 사유 (선택 사항, 디버깅용)
  - `created_at` (TIMESTAMP): 생성 일시
- **인덱스**: `(date, market, screen_config_hash)` 복합 인덱스를 생성하여 조회 성능을 극대화합니다.

## 3. 설정 파일 구조 (Config-driven Design)

모든 기간 설정은 **거래일(Trading Days)** 기준으로 통일합니다. (1년 = 252일)

한국 시장과 미국 시장 대상으로 하는 설정값을 별도로 작성한다. (조건은 동일하게 작성)

* 향후 각 시장별로 필터링 조건을 차별화할 수 있도록 하기 위함

YAML은 기존의 settings.yaml 파일을 사용한다. 

```
# 미너비니 트렌드 템플릿 필터 설정
common:
  year_trading_days: 252  # 52주 기준 거래일

filters:
  moving_averages:
    enabled: true
    rules:
      - "price > sma150"
      - "price > sma200"
      - "sma150 > sma200"
      - "sma50 > sma150"
      - "sma50 > sma200"
      - "price > sma50"

  sma200_trend:
    enabled: true
    lookback_days: 22    # 약 한 달(22거래일) 전과 비교
    min_slope: 0.0

  price_position:
    enabled: true
    low_rebound_ratio: 1.3
    high_proximity_ratio: 0.75

  relative_strength:
    enabled: true
    min_rs_rating: 70

  blue_dot:
    enabled: true        # Blue Dot 발생 종목만 필터링할지 여부
```

## 4. 상세 필터링 조건 해설 (AI 모델 전달용)

시스템 내의 모든 '1년' 단위 계산은 **252 거래일**을 기준으로 수행합니다.

### (1) 이동평균선 정배열 (Stage 2 확인)

- **로직**: `주가 > 50MA > 150MA > 200MA` 순서로 정배열되어야 합니다.
- **의미**: 장기적인 상승 추세가 확립되어 에너지가 위로 분출되는 상태입니다.

### (2) 200일선 상승 추세 (Trend Confirmation)

- **로직**: 오늘의 200일선 값이 **22 거래일(약 한 달)** 전의 값보다 높아야 합니다.
- **의미**: 장기 추세 자체가 하락을 멈추고 고개를 들고 있음을 보장합니다.

### (3) 52주 가격 위치 (신고가 근접성)

- **저가 대비 반등**: 현재 주가는 252일 최저가 대비 **최소 30% 이상** 상승한 상태여야 합니다.
- **고가 대비 근접**: 현재 주가는 252일 최고가 대비 **25% 이내**에 위치해야 합니다. (`Price >= High_252d * 0.75`)

### (4) Blue Dot 시그널 (선행 강세 지표)

- **로직**: 아래 두 조건을 동시에 만족할 때 `is_blue_dot = 1`로 판정합니다.
  1. **RS Line 신고가**: `종가 / 벤치마크 종가` 비율이 최근 252일 중 최고치입니다.
     * 벤치마크 지수는 미국 시장은 S&P500, 한국 시장은 KOSPI를 사용한다.
  2. **주가 비신고가**: 주가 자체는 아직 최근 252일 최고가에 도달하지 않았습니다.
- **의미**: 시장 대비 강세가 먼저 나타나 신고가 돌파를 예고하는 시그널입니다.

## 5. 상세 실행 워크플로우 (AI 모델 가이드)

1. **데이터 로딩**

   * 한국의 경우: `stock_prices`에서 기준일 포함 최소 300일 치 데이터를 로드합니다.
   * 미국의 경우: `us_stock_prices`에서 기준일 포함 최소 300일 치 데이터를 로드합니다.

2. **지표 산출**:

   - 252일(52주) 최고가/최저가를 계산합니다.
   - RS Line을 계산하고 252일 신고가 여부를 판단합니다.

3. **필터 검증**: Config 파일의 `enabled` 설정을 확인하며 AND 조건으로 모든 필터를 통과시킵니다.

   - 탈락 시 `failed_reason`에 사유를 기록합니다.

   - failed_reason는 디버깅 또는 개발 단계에서 선택적으로 사용하며, 운영 환경에서는 NULL일 수 있다.

   -  failed_reason 포맷 예시 (선택)

     예:

     ```
     "SMA200_DOWN"
     "RS<70"
     "PRICE_BELOW_50MA"
     ```

4. **결과 저장**: 통과한 종목 정보를 해당 시장에 맞는 minervini_screen_results_kr 또는 minervini_screen_results_us 테이블에 적재합니다.

## 6. Grafana 활용

사전 계산된 테이블을 사용하여 쿼리 시간을 **0.1초 이내**로 단축합니다.

SQL

```
SELECT symbol, name, rs_rating, IF(is_blue_dot=1, '🔵', '') as blue_dot
FROM minervini_screen_results_kr
WHERE date = '$date' AND market IN ($market)
ORDER BY rs_rating DESC;
```
