# 레퍼런스 결정 기록

## 기준 문서

- `docs/design_guide_01.md`

## 고정 레퍼런스 3종

### 1) Apple

- 차용: 절제된 여백, 낮은 채도 대비, 과하지 않은 모션
- 배제: 장식성 효과 중심의 과도한 글래스/광택 표현

### 2) Linear

- 차용: 높은 정보 밀도에서도 정돈된 레이아웃, 빠른 탐색 UX
- 배제: 과도한 테크 감성(짙은 대비, 복잡한 키보드 패턴) 전면 도입

### 3) Notion

- 차용: 섹션/정보 계층 분리, 단순한 카드 문법
- 배제: 문서형 편집 UI를 제품 전면으로 확장하는 패턴

## 적용 원칙 요약

- 화면 인상: 밝고 정제된 톤
- 구조: Hero > 탐색 > Featured > Grid > Secondary
- 카드: 메타는 조용하게, 제목/요약/행동 우선
- 인터랙션: `translateY(-2px)` 수준의 절제된 반응
