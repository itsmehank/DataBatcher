# 디자인 개선 범위 잠금 (Phase 5)

## 목적

`docs/design_guide_01.md` 후속 마감 단계에서 변경 범위를 명확히 고정하고, 회귀를 줄이기 위한 실행 기준을 정의한다.

## In Scope

- UI 스타일 정합성 개선 (간격, 계층, 타이포, 색 대비)
- 템플릿/아카이브 empty-loading-error 상태 정리
- 접근성 보완 (focus, 시맨틱, 대비)
- 반응형 안정화 (360/768/1024/1440 기준)
- 문서화 보강 (토큰 규칙, QA 보고서, 완료표)

## Out of Scope

- 백엔드 API/스키마/권한 정책 변경
- 신규 핵심 기능 추가 (예: 추천 엔진, 자동 분류)
- 인증 체계 재설계
- 데이터 마이그레이션

## DoD (측정 가능 기준)

- 템플릿 empty-state 중복/분리 노출: 0건
- 주요 뷰포트(360/768/1024/1440) 레이아웃 깨짐: 0건
- 링크/버튼 시맨틱 오류(a 내부 button 등): 0건
- 키보드 탭으로 주요 CTA 접근 가능: 100%
- `npm run build` 성공

## 단계별 게이트

1. 수정 후 개발 서버 재시작
2. 브라우저 강력 새로고침 후 시각 확인
3. `npm run build` 통과
4. 실행 보고서에 변경 내역 기록
