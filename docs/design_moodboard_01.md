# 무드보드 합의안

## 방향 문장

기능 화면이 아니라, 다시 방문하고 싶은 인사이트 아카이브 제품으로 보이게 한다.

## 시각 언어

- 배경: 옅은 쿨그레이 기반, 미세한 그라디언트
- 표면: 화이트 카드 + 소프트 섀도우
- 강조: 블루 계열 포인트 1색
- 대비: 텍스트 계층으로 강조, 경계선 남발 금지

## 타이포 톤

- Hero: 큰 문장 1개, 짧은 설명 1개
- 섹션 제목: 28~36px 계열
- 카드 제목: 20~24px 계열
- 메타: 12~13px 계열

## 컴포넌트 인상

- 네비: 반투명 + blur, 넓은 클릭 영역
- 카드: hover 시 미세한 상승, 버튼은 목적 중심으로 최소화
- Empty state: 한 영역에 메시지와 행동을 묶어 보여줌

## 배제 항목

- 네온/형광/과도한 광택 효과
- 과한 확대/회전/bounce 애니메이션
- 의미 없는 아이콘/배지 과다 노출
