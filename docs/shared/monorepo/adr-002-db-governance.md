# ADR-002: DB 거버넌스 및 마이그레이션 정책

## 상태

승인(Approved)

## 결정

- DB는 공통 도메인(`db/`)으로 관리한다.
- 마이그레이션 도구는 Alembic으로 고정한다.
- baseline migration을 현재 스키마 기준점으로 먼저 생성한다.
- 이후 스키마 변경은 migration-first로만 반영한다.
- `init` 스크립트는 bootstrap 용도로만 사용한다.

## 테스트 원칙

- DB 테스트는 `3307` 임시 포트 오버라이드만 사용한다.
- 코드/설정 파일에 `3307` 값을 저장하지 않는다.
- 테스트 종료 후 `3307` 컨테이너를 제거한다.
- 기존 `3306` DB는 비침범 유지한다.

## 변경 안전 규칙

- backward-compatible 원칙 준수: 확장 -> 전환 -> 정리
- 스키마 변경 PR은 영향 테이블/소비자/롤백 전략을 포함해야 함

## 영향

- 2단계 완료 전까지는 기존 init 기반 경로와 혼재 가능
- 2단계 게이트 통과 후 migration 중심 운영으로 전환
