# DataBatcher US Index 실행 가이드

본 문서는 DataBatcher 프로젝트에서 **미국 지수(S&P 500, Dow Jones, NASDAQ Composite)** 데이터를 수집하기 위한 단계별 안내서입니다.

**최종 업데이트**: 2026-02-06

## 프로젝트 개요

DataBatcher US Index는 미국 3대 주요 지수의 일봉 데이터 수집 및 기술적 지표 계산 시스템입니다.

- **데이터 소스**: FinanceDataReader (FDR) → Yahoo Finance
- **지원 지수**: S&P 500 (US500), Dow Jones (DJI), NASDAQ Composite (IXIC)
- **핵심 파이프라인**: 데이터 수집(collectors) → 지표 계산(indicators) → DB 저장(savers)

> **참고**: 미국 개별 주식(`us_stock_*`)과 별도의 테이블을 사용합니다.
> - `us_index_master`: 미국 지수 마스터
> - `us_index_prices`: 미국 지수 가격 (adj_close 없음)
> - `us_index_indicators`: 미국 지수 지표

### 대상 지수

| FDR Symbol | Yahoo Symbol | 이름 | market 값 |
|-----------|-------------|------|----------|
| US500 | ^GSPC | S&P 500 | SP500 |
| DJI | ^DJI | Dow Jones Industrial Average | DJI |
| IXIC | ^IXIC | NASDAQ Composite | IXIC |

## 1. 사전 요구사항

- **Python 3.10+** 권장 (3.9 이상 동작 가능)
- **pip** 또는 pipx
- **Docker + Docker Compose** (로컬 MySQL 실행 용도, 권장)

## 2. 최초 설치 및 실행 (Quick Start)

처음 시작하는 경우, 다음 5단계로 빠르게 시작할 수 있습니다.

**예상 소요 시간**: 3-5분

```bash
# 1. 가상환경 활성화 및 의존성 설치
source .venv/bin/activate  # 또는 .venv\Scripts\activate (Windows)
pip install -r requirements.txt

# 2. Docker MySQL 실행 및 DB 초기화 (테이블 생성)
cd docker && docker compose up -d && cd ..
mysql -h 127.0.0.1 -u YOUR_DB_USER -pYOUR_DB_PASSWORD market < scripts/migrations/add_us_index_tables.sql

# 3. US Index Master 동기화 (3개 지수 등록)
python scripts/us_index_sync_master.py

# 4. 과거 데이터 수집 (최근 1년)
python scripts/us_index_bulk_update.py --start 2025-01-01 --end 2025-12-31

# 5. 일일 업데이트 테스트
python scripts/us_index_daily_update.py --all --force
```

## 3. 상세 설치 가이드

### Step 1: 환경 설정 및 검증

#### 1-1. 가상환경 및 의존성 설치

```bash
# 가상환경 생성 (처음 한 번만)
python3 -m venv .venv

# 가상환경 활성화
source .venv/bin/activate  # Linux/Mac
# 또는
.venv\Scripts\activate  # Windows

# 의존성 설치
pip install -r requirements.txt
```

#### 1-2. Docker MySQL 실행 (로컬 개발 환경)

```bash
# MySQL 컨테이너 실행
cd docker
docker compose up -d
cd ..

# 컨테이너 상태 확인
docker ps | grep databatcher
```

#### 1-3. US Index 테이블 생성

```bash
# Migration SQL 실행
mysql -h 127.0.0.1 -u YOUR_DB_USER -pYOUR_DB_PASSWORD market < scripts/migrations/add_us_index_tables.sql

# 테이블 확인
mysql -h 127.0.0.1 -u YOUR_DB_USER -pYOUR_DB_PASSWORD market -e "SHOW TABLES LIKE 'us_index%';"
# Expected: us_index_master, us_index_prices, us_index_indicators
```

#### 1-4. FDR API 테스트 (선택)

```bash
# FDR US Index API 동작 확인
python scripts/probes/fdr_us_index_probe.py --all-indices --start 2024-01-01 --end 2024-01-31
```

**예상 출력**: 각 지수별 Open/High/Low/Close/Adj Close/Volume 컬럼, ~20일 데이터

### Step 2: US Index Master 동기화

**목적**: S&P 500, Dow Jones, NASDAQ Composite 지수를 `us_index_master` 테이블에 등록

```bash
python scripts/us_index_sync_master.py
```

**예상 결과**: 3개 지수(US500, DJI, IXIC) 등록

**확인 방법**:
```bash
mysql -h 127.0.0.1 -u YOUR_DB_USER -pYOUR_DB_PASSWORD market -e "SELECT * FROM us_index_master;"
# Expected: 3 rows, all ACTIVE
```

**참고**: 지수 목록은 스크립트에 하드코딩되어 있습니다. FDR에는 지수 이름 조회 API가 없으므로 이름도 하드코딩입니다.

### Step 3: 과거 데이터 대량 수집 (Bulk Collection)

**목적**: 3개 지수의 과거 가격 데이터와 지표를 수집

```bash
# 3-1. 전체 지수, 최근 1년 수집 (추천 시작)
python scripts/us_index_bulk_update.py --start 2025-01-01 --end 2025-12-31

# 3-2. 전체 지수, 5년치 수집 (프로덕션 권장)
python scripts/us_index_bulk_update.py --start 2020-01-01 --end 2025-12-31

# 3-3. S&P 500만 수집
python scripts/us_index_bulk_update.py --start 2024-01-01 --end 2024-12-31 --market SP500

# 3-4. Dow Jones만 수집
python scripts/us_index_bulk_update.py --start 2024-01-01 --end 2024-12-31 --market DJI

# 3-5. NASDAQ Composite만 수집
python scripts/us_index_bulk_update.py --start 2024-01-01 --end 2024-12-31 --market IXIC
```

**예상 소요 시간**: 1-2분 (3개 지수만이므로 매우 빠름)

**수집 결과 확인**:
```bash
# 가격 데이터 확인
mysql -h 127.0.0.1 -u YOUR_DB_USER -pYOUR_DB_PASSWORD market -e "
  SELECT symbol, COUNT(*) as rows, MIN(date) as oldest, MAX(date) as newest
  FROM us_index_prices
  GROUP BY symbol;
"
# Expected: US500 ~250, DJI ~250, IXIC ~250 (1년 기준)

# 지표 데이터 확인
mysql -h 127.0.0.1 -u YOUR_DB_USER -pYOUR_DB_PASSWORD market -e "
  SELECT symbol, indicator, COUNT(*) as rows
  FROM us_index_indicators
  GROUP BY symbol, indicator;
"
# Expected: 각 지수/indicator별로 날짜 수만큼 row가 누적됨
```

### Step 4: 일일 업데이트 테스트

**목적**: 일일 업데이트가 정상 동작하는지 확인

```bash
# 4-1. 전체 지수 업데이트 (추천)
python scripts/us_index_daily_update.py --all --force

# 4-2. 특정 지수만 업데이트
python scripts/us_index_daily_update.py --symbols US500 --force

# 4-3. 특정 마켓만 업데이트
python scripts/us_index_daily_update.py --all --market SP500 --force
```

**예상 출력**:
```
Loaded 3 indices from us_index_master (market=ALL)
US500: 가격 X건 처리(insert-only)
US500: Y개 날짜 처리, 지표 Z건 저장
DJI: 가격 X건 처리(insert-only)
DJI: Y개 날짜 처리, 지표 Z건 저장
```

**동작 확인 포인트**:

## 4. 정규 운영 방법

### 4.1. 주간 작업: Index Master 동기화

**실행 주기**: 매주 1회 (일요일 새벽 권장)

```bash
python scripts/us_index_sync_master.py
```

**참고**: 3개 지수는 하드코딩되어 있어 변동 가능성이 거의 없지만, 안전을 위해 주간 실행을 권장합니다.

---

### 4.2. 일일 작업: 데이터 업데이트

**실행 주기**: 매 영업일 US 장마감 후 (한국시간 기준 오전 6-7시)

> **참고**: US 시장 마감 시간
> - 정규장: 16:00 ET (동부 시간)
> - 서머타임 시: 한국시간 오전 5시
> - 비서머타임 시: 한국시간 오전 6시

```bash
# 전체 지수 업데이트
python scripts/us_index_daily_update.py --all --force
```

**동작 방식**:
1. 최근 50일 가격 데이터 수집 (INSERT ONLY - 기존 데이터 보존)
2. DB에서 최근 250일 데이터 조회 (warmup 포함)
3. 지표 계산 (SMA 5/20/40)
4. 최신 날짜부터 역순 처리, 완료된 날짜 만나면 조기 중단
5. 지표 저장 (INSERT ONLY)

---

### 4.3. 재수집 (Backfill)

특정 기간의 데이터를 다시 채우려면 `us_index_bulk_update.py`를 사용합니다.

```bash
python scripts/us_index_bulk_update.py --start 2024-01-01 --end 2024-12-31
```

**중요**: `us_index_bulk_update.py`는 **INSERT ONLY 모드**로 동작합니다. 기존 데이터는 덮어쓰지 않습니다.

## 5. 설정 시스템

### 5.0. 코드 기준 진실 소스(SoT)

문서와 실제 동작이 다를 때는 아래 코드를 기준으로 판단합니다.

- US 지수 일일 증분 처리(50일 수집/250일 지표/역순 중단): `scripts/us_index_daily_update.py`
- US 지수 과거 일괄 수집(Bulk): `scripts/us_index_bulk_update.py`
- 지수 목록 로딩/마켓 필터: `core/us_index_symbol_loader.py`
- DB 저장 정책(insert_only/upsert): `core/db_manager.py`

### 5.1. US Index 지표 설정

**config/settings.yaml**의 `indicators_us_index` 섹션:

```yaml
indicators_us_index:
  materialization:
    mode: long
    table_long: us_index_indicators

  pipeline:
    - name: sma
      params: { window: 5, column: close }
      save: true
    - name: sma
      params: { window: 20, column: close }
      save: true
    - name: sma
      params: { window: 40, column: close }
      save: true
```

### 5.2. 시장 마감 시간 설정

```yaml
markets:
  close_times:
    NYSE: "16:00"   # US Eastern Time (S&P 500, DJI, IXIC 모두 동일)
  safe_delay_minutes: 30
```

## 6. 자동화 설정

### 6.1. Cron (Linux/Mac)

```bash
# crontab 편집
crontab -e

# 추가할 내용:

# 주간: 일요일 새벽 3시에 US Index Master 동기화

# 일일: 평일 오전 7시(US 장마감 후)에 전체 업데이트

```

> **참고**: 서머타임 기간에는 오전 6시로 조정 권장

### 6.2. Windows Task Scheduler

1. **작업 스케줄러** 실행
2. **기본 작업 만들기** 선택
3. **트리거**: 매일 오전 7시 (또는 오전 6시)
4. **동작**: 프로그램 시작
   - 프로그램: `C:\path\to\DataBatcher\.venv\Scripts\python.exe`
   - 인수: `scripts/us_index_daily_update.py --all --force`
   - 시작 위치: `C:\path\to\DataBatcher`

## 7. FAQ 및 트러블슈팅

### Q1. FDR 데이터 수집 실패

**원인**:
- 네트워크 문제
- FDR/Yahoo Finance 서비스 일시 장애

**해결**:
```bash
# 1. FDR API 동작 확인
python scripts/probes/fdr_us_index_probe.py --symbol US500 --start 2024-01-01 --end 2024-01-31

# 2. 수동 테스트
python -c "
import FinanceDataReader as fdr
df = fdr.DataReader('US500', '2024-01-01', '2024-01-31')
print(df.head() if df is not None else 'Failed')
"
```

---

### Q2. Volume이 0인 데이터

**원인**: 일부 지수(특히 DJI)에서 Volume이 0으로 반환될 수 있습니다.

**해결**: 지수의 Volume은 참고용이며 지표 계산에 영향을 미치지 않습니다. 정상 동작입니다.

---

### Q3. 시간대 관련 이슈

**원인**: US Eastern 시간 계산 오류

**확인**:
```python
from datetime import datetime
try:
    from zoneinfo import ZoneInfo
    us_eastern = ZoneInfo("America/New_York")
except ImportError:
    import pytz
    us_eastern = pytz.timezone("America/New_York")

now_et = datetime.now(us_eastern)
print(f"US Eastern: {now_et}")
```

**해결**: `zoneinfo` 또는 `pytz` 라이브러리 설치 확인

---

### Q4. 지표 NaN 값 발생

**원인**: Warmup period 데이터 부족 (예: SMA(40)은 최소 40일 필요)

**해결**:
- 더 긴 기간의 데이터 수집 (`us_index_bulk_update.py`)
- NaN 값은 DB에 NULL로 저장됨 (정상 동작)

---

### Q5. "us_index_master에서 ACTIVE 지수를 찾을 수 없습니다" 에러

**원인**: `us_index_sync_master.py`가 실행되지 않음

**해결**:
```bash
python scripts/us_index_sync_master.py
```

## 10. 한국 지수 vs 미국 지수 비교

| 항목 | 한국 지수 (KR Index) | 미국 지수 (US Index) |
|------|-------------------|-------------------|
| 데이터 소스 | pykrx | FinanceDataReader (Yahoo) |
| 대상 지수 | KOSPI (1001), KOSDAQ (2001) | S&P 500 (US500), DJI, IXIC |
| 마스터 테이블 | kr_index_master | us_index_master |
| 가격 테이블 | kr_index_prices | us_index_prices |
| 지표 테이블 | kr_index_indicators | us_index_indicators |
| 설정 키 | indicators_kr_index | indicators_us_index |
| 지표 | SMA(5,20), EMA(12,26) | SMA(5,20,40) |
| 동기화 스크립트 | kr_index_sync_master.py | us_index_sync_master.py |
| 대량 수집 | kr_index_bulk_update.py | us_index_bulk_update.py |
| 일일 업데이트 | kr_index_daily_update.py | us_index_daily_update.py |
| 장마감 시간 | 16:00 KST | 16:00 ET |
| 자동화 추천 시각 | 17:00 KST | 07:00 KST |
| adj_close | 없음 | 없음 |
| 이름 조회 | pykrx API | 하드코딩 (FDR 미지원) |
