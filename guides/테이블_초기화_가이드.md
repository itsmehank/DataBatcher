# 테이블 초기화 가이드

## 개요

`apps/ingest-databatcher/ops/shell/truncate_all_tables.sh`는 DataBatcher의 **모든 테이블 데이터를 삭제**하는 셸 스크립트입니다.
테이블 구조(스키마)는 유지되며, 데이터만 삭제됩니다.

---

## 사전 주의사항

- **삭제된 데이터는 복구할 수 없습니다.**
- 실행 시 확인 프롬프트(`yes/no`)가 표시됩니다.
- Docker MySQL이 실행 중이어야 합니다.

---

## 실행 방법

```bash
cd /path/to/DataBatcher
bash apps/ingest-databatcher/ops/shell/truncate_all_tables.sh
```

실행하면 대상 테이블 목록이 표시되고, `yes`를 입력해야 진행됩니다.

---

## 실행 후 후속 작업

- `init_db.py` 재실행 **불필요** (테이블 구조가 유지되므로)
- 바로 bulk 재수집 가능:
  ```bash
  bash apps/ingest-databatcher/ops/shell/bulk_all.sh
  ```

---

## TRUNCATE vs DROP 비교

| 항목 | TRUNCATE | DROP |
|------|----------|------|
| 데이터 삭제 | O | O |
| 테이블 구조 유지 | O | X |
| AUTO_INCREMENT 리셋 | O | - |
| 속도 | 빠름 (로그 최소화) | - |
| 이후 작업 | 바로 사용 가능 | `init_db.py` 재실행 필요 |

---

## 일반적 사용 시나리오

1. **개발환경 리셋**: 테스트 데이터를 모두 지우고 깨끗한 상태에서 시작
2. **전체 재수집**: 스키마 변경 없이 데이터만 새로 수집할 때
3. **디스크 공간 확보**: 대용량 가격 데이터를 빠르게 삭제할 때

**전형적인 워크플로우**:
```bash
# 1. 전체 데이터 삭제
bash apps/ingest-databatcher/ops/shell/truncate_all_tables.sh

# 2. 전체 재수집
bash apps/ingest-databatcher/ops/shell/bulk_all.sh
```
